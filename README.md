# Mejrup Skytteforening

Statisk hjemmeside uden build-trin eller afhængigheder. Åbn `index.html` i en browser for at se siden lokalt.

## GitHub Pages

Push filerne til GitHub. Vælg **Settings → Pages → Deploy from a branch**, vælg den relevante branch og **/ (root)**, og klik **Save**.

Indholdet ligger i `index.html`, og designet ligger i `style.css`.
